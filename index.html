ความตั้งใจและแนวทางการพัฒนา

1. เหตุผลที่อยากเรียน Full Stack Web Development

เหตุผลที่อยากเรียนวิชา Full Stack Web Development เพราะต้องการเข้าใจกระบวนการสร้างเว็บไซต์และเว็บแอปพลิเคชันแบบครบวงจร ตั้งแต่การออกแบบหน้าจอที่ผู้ใช้งานมองเห็น (Front-end) ไปจนถึงการทำงานของระบบเซิร์ฟเวอร์และการจัดการฐานข้อมูล (Back-end) เพื่อให้สามารถสร้างสรรค์ผลงานหรือระบบที่ใช้งานได้จริงด้วยตนเองตั้งแต่นับหนึ่งจนเสร็จสมบูรณ์

2. ความคาดหวังต่อวิชานี้

คาดหวังว่าจะได้รับความรู้พื้นฐานที่แน่นหนาในการใช้เทคโนโลยีสำหรับการพัฒนาเว็บ เช่น HTML, CSS, JavaScript ตลอดจนเฟรมเวิร์กและเครื่องมือฝั่งหลังบ้าน สามารถนำความรู้ที่ได้ไปประยุกต์ใช้ในการทำโปรเจกต์จริง เข้าใจหลักการเชื่อมต่อระบบอย่างเป็นขั้นตอน และเตรียมความพร้อมสำหรับการฝึกงานและการทำงานในสายงานนักพัฒนาซอฟต์แวร์ในอนาคต

3. จุดอ่อนที่ต้องพัฒนาเกี่ยวกับทักษะ Programming และแนวทางการพัฒนา

จุดอ่อนในปัจจุบันคือการคิดวิเคราะห์เชิงตรรกะ (Logical Thinking) เมื่อเจอโจทย์ที่ซับซ้อน และการจำโครงสร้างคำสั่งหรือไวยากรณ์ (Syntax) ของภาษาโปรแกรมที่ยังไม่แม่นยำนัก แนวทางการพัฒนาตนเองคือการฝึกเขียนโค้ดด้วยตนเองอย่างสม่ำเสมอ ทบทวนบทเรียนหลังเลิกเรียน ศึกษาตัวอย่างโค้ดจากแหล่งเรียนรู้ต่าง ๆ และฝึกแก้ปัญหาจากการลงมือทำโปรเจกต์ขนาดเล็กบ่อย ๆ

เว็บไซต์ที่ชื่นชอบและได้รับแรงบันดาลใจ

เว็บไซต์ที่ชื่นชอบและใช้เป็นแรงบันดาลใจในการเรียนรู้การเขียนโค้ดคือ: MDN Web Docs (Mozilla Developer Network) และ GitHub
